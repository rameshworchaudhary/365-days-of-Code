# Day 3 — Count Vowels in a String

## 🧩 Problem

Given a string, count the total number of vowels present in the string.

The vowels are:

```text
a, e, i, o, u
A, E, I, O, U
```

### Example

**Input:**

```text
Ishwor
```

**Output:**

```text
Number of vowels in the string: 2
```

The vowels are `I` and `o`.

## 💡 Approach

I used a `for` loop to traverse every character of the string.

For each character, I checked whether it is a vowel using an `if` condition.

If the character is a vowel, I increment the `count` variable by `1`.

## 💻 Language

C++

## ⏱️ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

## 🧠 What I Learned

* How to traverse a string using a loop
* How to access individual characters using `s[i]`
* How to check multiple conditions using the `||` operator
* How to count specific characters in a string
* Handling both uppercase and lowercase vowels
