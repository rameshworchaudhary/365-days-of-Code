# Day 1 — Two Sum

## Problem
Given an array of integers and a target value, find the indices of two numbers whose sum equals the target.

## Example

Input:
nums = [1, 2, 3, 4, 5]
target = 7

Output:
[1, 4]

## Approach
Used a brute-force approach with nested loops.
For every element, I check the elements after it to find a pair whose sum equals the target.

## Complexity

- Time Complexity: O(n²)
- Space Complexity: O(1)

## Language
C++

## What I Learned
- Array indexing
- Nested loops
- Brute-force problem solving
- Time and space complexity
