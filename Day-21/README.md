# Day 21 — Find the Intersection of Two Arrays

## Problem

Given two integer arrays, find the elements that are present in both arrays.

## Example

Input:
Array 1 = [1, 2, 3, 4, 5, 6]
Array 2 = [7, 2, 4, 3, 11, 12]

Output:
The common element is: 2
The common element is: 3
The common element is: 4

## Approach

Used a brute-force approach with nested loops.

For every element of the first array, I compare it with every element of the second array.

If both elements are equal, I print the common element.

## Complexity

- Time Complexity: O(n²)
- Space Complexity: O(1)

## Language

C++
